# Literature Dataset for Computer Vision-Based Plant and Plant Organ Counting

## Overview

This repository provides the literature dataset compiled for a review manuscript on computer vision-based plant and plant organ counting. The dataset contains 904 publications published between 2017 and 2025, covering computer vision techniques for plant and plant organ counting, phenotyping, and yield estimation.

## Dataset

**File:** `literature.csv`

The dataset includes the following fields:

- **Title:** Publication title
- **Abstract:** Publication abstract
- **Year:** Publication year
- **Country:** Country associated with the publication
- **Object:** Plant species or study object
- **Platform:** Image acquisition platform
- **Image Type:** Imaging modality
- **Author Keywords:** Author-provided keywords

Author-provided keywords are available for 841 of the 904 publications.
